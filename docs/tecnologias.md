# 🛠️ Tecnologias do Projeto

## Objetivo

Este documento apresenta as tecnologias escolhidas para o desenvolvimento do sistema Hora do Remédio.

---

## Frontend

### React

O React será utilizado para desenvolver a interface do sistema.

A escolha foi feita porque permite criar telas modernas, organizadas e de fácil manutenção.

---

## Linguagem

### JavaScript

O JavaScript será utilizado junto com o React para criar as funcionalidades do sistema.

---

## Backend e Banco de Dados

### Firebase
### SQLite

O Firebase será utilizado como backend do projeto, facilitando o armazenamento das informações sem a necessidade de criar um servidor próprio.

---

## Banco de Dados

### Firestore
### SQLite

O Firestore será utilizado para armazenar os dados dos medicamentos, horários e histórico.

---

## Ambiente de Desenvolvimento

### Visual Studio Code

O Visual Studio Code será utilizado para escrever e organizar o código do projeto.

---

## Controle de Versão

### GitHub

O GitHub será utilizado para armazenar o projeto, controlar as versões e organizar a documentação.

---

## Justificativa da Escolha

As tecnologias foram escolhidas por serem simples, modernas e adequadas para o desenvolvimento de um MVP acadêmico.

Além disso, permitem criar uma aplicação web responsiva, podendo ser acessada tanto pelo computador quanto pelo celular.
